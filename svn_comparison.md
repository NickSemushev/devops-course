# Git vs SVN

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это просто указатель на коммит, создаётся мгновенно. В SVN ветка — это копирование директории на сервере, медленно и занимает место.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN централизованная, все коммиты идут на сервер. Без сети коммит невозможен.

## 3. В каких сценариях SVN до сих пор предпочтительнее Git?
- Legacy-проекты (госсектор, банки), где миграция дороже поддержки.
- Жёсткий контроль прав на отдельные папки (SVN умеет, Git — нет).
- Огромные бинарные файлы, где не нужны ветки.
